# Evaluation kit map data, Ireland

Map files for the Creating Better care tech evaluation kit, one for each of the 31 local authorities in Ireland.

Sources
- Boundaries. CSO Electoral Divisions, National Statistical Boundaries 2022, generalised to 20 metres. Tailte Éireann and the Central Statistics Office, CC BY 4.0.
- Census 2022 Small Area Population Statistics by electoral division. Central Statistics Office, CC BY 4.0.
- Pobal HP Deprivation Index 2022 by electoral division. Pobal, CC BY 4.0.

Shapes are simplified for display. Figures are totals by area and hold nothing about any person.
